# Copy — rótulos que o protótipo v3 renomeia

Regra (plano, princípio 5): a chave de tradução **é** o texto em português (`docs/i18n.md`), e a
suíte E2E casa por nome acessível (`getByRole(..., { name })`, 110 ocorrências, zero `data-testid`).
Logo um rótulo só muda quando, **no mesmo commit**, (a) os catálogos `public/i18n/{en,es,ar,xx}.json`
recebem a chave nova e (b) os specs E2E que o citam são atualizados. E só muda se a redação nova for
melhor nos três perfis de exibição, não por capricho do protótipo.
