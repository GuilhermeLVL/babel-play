# Protótipos de tela

HTML autocontidos que o dono usa como "Figma" do app. Abra o `.html` direto no navegador. Os arquivos `*-src/` são as fontes de quem gera o HTML (`montar.mjs`); `_comum/` guarda o que é idêntico entre eles.

## Fontes (`*-src/`) e `_comum/`

Cada `*-src/` monta o seu HTML: `node docs/prototipos/<nome>-src/montar.mjs` (a saída é byte a byte igual à versionada). `montar.mjs` e `scripts/polimento/trazer-css.mjs` leem primeiro a pasta do protótipo e, se o arquivo não estiver lá, `_comum/`. Um arquivo da pasta tem prioridade sobre o de `_comum/` (é assim que as poucas versões diferentes de `jogos4.js`, `telas.js`, `telas2.js` e `sentidos.js` convivem). Para alterar um arquivo comum, edite em `_comum/` e remonte os cinco HTMLs.

`*-src` e `_comum` ficam fora do lint e do prettier.

## Scripts soltos (histórico)

`verifica-*.mjs`, `fotos-jogos.mjs` e `colisoes-css.mjs` são verificações das rodadas de design v4 (Playwright + axe), com caminhos de uma máquina antiga. Não rodam sem ajuste. `gerar-css-do-prototipo.mjs` ainda serve para regenerar `src/styles/prototipo.css`.
