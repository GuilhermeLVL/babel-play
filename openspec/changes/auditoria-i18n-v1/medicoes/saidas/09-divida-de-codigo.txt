Ressalva: "template literal com ${}" e "tag inline" são censos de PADRÃO, não de
string de tela. Um template literal pode montar uma classe CSS ou uma URL; uma tag
inline pode envolver um ícone. O número alto não é dívida de tradução por inteiro —
é o teto dela. É por isso que os próprios documentos dão dois valores diferentes.
